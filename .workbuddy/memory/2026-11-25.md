- README 已更新协议、三种场景、关键实现表与多实例需 Redis/sticky session 的注意事项。

## Chat 打字节奏与光标优化

- 新增 `src/lib/chat-typing.ts`：TypingQueue 按时间片提交字符（文本 24ms/3 字、表格 34ms/2 字、公式 40ms/2 字、代码 48ms/1 字），按内容类型识别并区分代码块状态，避免原始 chunk 直接 setState 造成爆闪。
- `src/pages/chat/index.tsx`：网络帧只入队；正常结束/异常/取消时 `flushAll()` 补齐已收字符；工具栏展示当前分段类型与节奏。
- 打字光标从内联 span 改为绝对定位覆盖层，在 rAF 中每帧最多读一次末尾 Range 位置，用 transform 更新，避免强制同步布局；resize 时重定位。
- 验证：`pnpm build` 成功；`/chat` 返回 200；流式代理仍完整输出 187 帧。

## Chat 消息滚动策略

- `src/pages/chat/index.tsx`：只在用户贴底（24px 误差）时自动滚到底；wheel/touch 向上或长消息内部滚动会立刻暂停自动滚动，显示「回到底部」按钮；用户看历史时内容追加在下方，视口 scrollTop 保持不变。
- 所有 `scrollTop` / `scrollHeight` / `clientHeight` 读写合并到单个 rAF，每帧只读一次；不再用 `scrollIntoView` 高频调用。
- `src/pages/chat/index.module.scss`：单条气泡 `max-height: 240px` + 内部 `overflow-y: auto`，`overscroll-behavior: contain` 阻止滚动链穿透；光标定位补回气泡自身 scrollTop/scrollLeft。
- 验证：`pnpm build` 成功；`/chat` 返回 200；流式接口仍完整输出 187 帧。
